## 1. Executive Summary

This spec details the end-to-end architecture and UI overhaul for GYMBro's **Stats** and **Recovery** screens. It establishes a rich, customizable telemetry ecosystem that extracts deep metrics from Garmin (VO2 Max, Fitness Age, Body Battery, HRV Status, Sleep Stages, Training Status, Stress, SpO2, and Intensity Minutes), enforces smart conditional rendering when data is missing, adds a widget customization modal, extends trend filtering up to 1 Year (7D, 30D, 90D, 6M, 1Y), and fixes all mobile UI bounding and label clipping issues.

## 2. Telemetry Ingestion & Data Architecture

### 2.1 Garmin API Fetch Expansion ([`app/garmin/sync.py`](file:///Users/davidmcinnis/codes/gymbro/app/garmin/sync.py))
During unified Garmin sync, the backend fetches and normalizes the following endpoints:
1. `garmin_api.get_max_metrics(date_str)` -> Extracts `vo2MaxRunning`, `vo2MaxCycling`, `fitnessAge`, `userRacePredictions`.
2. `garmin_api.get_training_status(date_str)` -> Extracts `trainingStatusKey` (Productive, Recovery, Maintaining, Overreaching), `acuteTrainingLoad`, `chronicTrainingLoad`.
3. `garmin_api.get_body_battery(date_str)` -> Extracts `bodyBattery` charged/drained levels and curve.
4. `garmin_api.get_sleep_data(date_str)` -> Extracts `sleepScores`, `sleepTimeSeconds`, `deepSleepSeconds`, `lightSleepSeconds`, `remSleepSeconds`, `awakeSeconds`.
5. `garmin_api.get_hrv_data(date_str)` -> Extracts `lastNightAvg`, `weeklyAvg`, `baseline` (Low / Balanced / High).
6. `garmin_api.get_spo2_data(date_str)` & `get_respiration_data(date_str)` -> Extracts average SpO2 % and nightly breaths per minute.

### 2.2 Unified Single Source of Truth Table (`biometrics_daily`)
All extracted metrics are upserted into `biometrics_daily`:
```sql
CREATE TABLE IF NOT EXISTS public.biometrics_daily (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  user_id bigint REFERENCES public.users(id) ON DELETE CASCADE NOT NULL,
  date date NOT NULL,
  resting_hr numeric,
  hrv numeric,
  hrv_status text,
  sleep_score numeric,
  sleep_hours numeric,
  deep_sleep_hours numeric,
  rem_sleep_hours numeric,
  light_sleep_hours numeric,
  body_battery numeric,
  vo2_max numeric,
  fitness_age numeric,
  training_status text,
  acute_load numeric,
  stress_level numeric,
  spo2 numeric,
  respiration numeric,
  source text DEFAULT 'garmin',
  updated_at timestamp with time zone DEFAULT timezone('utc'::text, now()),
  UNIQUE(user_id, date)
);
```

## 3. UI Component Architecture & Widget Registry

### 3.1 Conditional Rendering Rule
A telemetry card will render ONLY if:
1. The user has enabled it in their **Widget Preferences** modal (`enabledWidgets` array in local state/storage).
2. The database contains valid, non-null telemetry for the selected user/period.
3. If no data exists and the user has not connected Garmin/HealthKit, a sleek **"Connect Health Devices"** callout card renders with a 1-tap modal trigger.

### 3.2 Recovery Tab Overhaul ([`recovery.tsx`](file:///Users/davidmcinnis/codes/gymbro/gymbro-frontend-expo/app/%28tabs%29/recovery.tsx))
- **Header**: Daily Readiness Meter (0-100 Score combining HRV, Body Battery, Sleep, & RHR).
- **Time Range Selectors**: `7D`, `30D`, `90D`, `6M`, `1Y` live range filter pills.
- **Widgets Suite**:
  1. **HRV & Autonomic Recovery Card**: Displays 7-day HRV moving average, status badge (Balanced / Unbalanced), and rMSSD trend line.
  2. **Sleep Architecture Card**: Horizontal stacked progress bar representing Deep, REM, Light, and Awake hours + Sleep Score.
  3. **Body Battery & Stress Charge Meter**: Shows current Body Battery energy (1-100) alongside average stress levels.
  4. **Respiration & Blood Oxygen (SpO2) Card**: Nightly SpO2 % and respiration rate.

### 3.3 Stats Tab Overhaul ([`stats.tsx`](file:///Users/davidmcinnis/codes/gymbro/gymbro-frontend-expo/app/%28tabs%29/stats.tsx))
- **Header**: Athlete Baselines & PR Badges (5K, 10K, Half, Longest Run, VO2 Max badge, Fitness Age).
- **Time Range Selectors**: `7D`, `30D`, `90D`, `6M`, `1Y` live range filter pills.
- **Widgets Suite**:
  1. **Garmin Training Status & Acute Load Widget**: Displays current training phase (Productive, Maintaining, Recovery) and Acute Load score.
  2. **Running Pace & Efficiency Graphs**: Scrollable bar charts displaying min/km pace and HR efficiency.
  3. **Weekly Volume & Distance Graphs**: Scrollable distance bar chart with total km/miles.
  4. **Live Device Inspector & Pass-Through Card**: Synced workout stream with source badges.

### 3.4 Customization Modal (`WidgetCustomizeModal.tsx`)
- Tapping **"⚙️ Customize Widgets"** opens a modal displaying a list of all available cards with toggle switches.
- Preferences persist in `AsyncStorage` under `@gymbro_widget_prefs`.

## 4. Mobile Layout & Bounding Fixes

1. **Flexible Container Layouts**: Replace static heights (`height: 180`) with `minHeight` and `padding` to prevent content truncation.
2. **Text & Label Wrapping**: Use `flexWrap: 'wrap'` and `numberOfLines={1}` with `ellipsizeMode="tail"` for title/subtitle text.
3. **Horizontal Graph Scrolling**: Wrap all bar charts in `<ScrollView horizontal showsHorizontalScrollIndicator={false}>` with column `minWidth: 54` to ensure day/month labels never overlap or clip.
