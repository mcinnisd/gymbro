# Project Agent Guidelines — Superpowers Methodology

This repository is configured with the **Superpowers** agentic skills framework (`obra/superpowers`).

## Skill Activation Rule

- **Flexible & Optional Invocation**: Superpowers skills (such as `brainstorming`, `systematic-debugging`, `test-driven-development`, `writing-plans`, `subagent-driven-development`, `verification-before-completion`, `requesting-code-review`) are optional tools and guidelines, NOT mandatory requirements.
- Use skills when they add clear value or when explicitly requested by the user.
- For small, straightforward, or direct tasks, proceed directly without forcing heavy skill workflows or mandatory process gates.
- Prioritize user intent, flexibility, and speed over rigid adherence to skill checklists.
